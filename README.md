# CampusFlow — Campus Helpdesk Ticket Manager

CampusFlow is a Python command-line helpdesk application designed for campus staff to record problems, prioritize work, assign responsibility, and track progress efficiently.

## Team Members & Roles
- **Engineer A**: Ticket creation, input validation, priority engine, and associated tests.
- **Engineer B**: Assignment, status workflow, work queue, reporting, persistence, and associated tests.

## Requirements & Setup
- **Python Version**: Python 3.8+
- **Setup**: Clone the repo, create a virtual environment, and run the app.

```bash
python3 -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
